# Project Map

> Navigation cache. Source files are authoritative.

## Project

Next.js and React frontend for language learning, with UIFlow-owned stateful practice experiences.

## Areas

- `src/app/` — route-colocated pages, UIFlow definitions, client views, and server actions
- `src/components/ui/` — shared UI primitives
- `src/components/common/app-sidebar.tsx` — application navigation
- `src/lib/serverBackedApiCalls.ts` — authenticated backend HTTP calls using the user cookie
- `src/lib/types/` — backend request and response contracts

## Word Practice

- `src/app/word-practice/_flows/wordPracticeFlow.tsx` — queue loading, generation, answer submission, and exercise progression
- `src/app/word-practice/_client_components/WordPracticeView.tsx` — one-at-a-time practice and capacity UI
- `src/app/word-practice/_server_actions/` — server-only backend adapters
- `src/lib/types/responses/WordPracticeQueueResponse.ts` — queue and exercise response types

## Invariants

- Stateful feature behavior is owned by typed UIFlow steps; views emit intent and action steps call APIs.
- Word Practice generation requests ten vocabulary words and is allowed only when the resulting vocabulary count stays at or below fifteen.
- Correct answers leave the local queue after feedback; incorrect answers remain and rotate back through the queue.
